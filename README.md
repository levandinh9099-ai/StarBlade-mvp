# StarBlade-mvp
《星刃：星座觉醒》是一款俯视角动作地牢游戏。玩家选择星座角色，搭配主星体和辅星体，在房间制地牢中与敌人战斗、挑战首领，并通过不断变化的构筑体验不同战斗风格。 每名角色都有专属的普通攻击和两个平级主动技能，没有被动技能。白羊擅长快速近战与突进爆发；金牛挥动重锤、操控碎石，兼具重击与防护；天秤投掷回旋星镖，并用力场控制战场；天蝎则结合毒刃、突刺和持续伤害。移动、攻击、施放技能和闪避需要玩家主动操作，技能选择也会影响走位与输出节奏。 星体搭配是构筑的核心。主星体会同时改变角色两个技能的机制和视觉表现，例如附加火焰、回复、爆炸、聚敌或地形屏障；辅星体则影响相位的触发倾向和增益，不改变技能本身。玩家可以围绕技能强化输出，也可以选择续航、控制或防御路线。星体搭配是构筑的核心。主星体会同时改变角色两个技能的机制和视觉表现，例如附加火焰、回复、爆炸、聚敌或地形屏障；辅星体则影响相位的触发倾向和增益，不改变技能本身。玩家可以围绕技能强化输出，也可以选择续航、控制或防御路线。
战斗中，普通攻击和技能命中会积攒星能，并根据战斗表现触发四种相位：
- 合相：短时间内用两个技能命中同一敌人，强化双技能伤害并触发额外效果。
- 拱相：在时限内累计命中，提升星能回复并缩短技能冷却。
- 六合：连续命中且未受到伤害，获得伤害加成，并减少受击对技能施放的干扰。
- 刑克：生命值较低时施放技能，换取更高伤害，同时承担更高风险。
相位激活后，星能槽蓄满即可释放对应的星座相位必杀。每个角色都有四种专属必杀，例如金牛的陨石、岩脉壁垒、连续碎岩重击和磐石反噬；天秤拱相必杀则会令全体敌人静止 2 秒，并立即将自身两项技能的当前剩余冷却减半。必杀释放后进入下一轮战斗循环，鼓励玩家持续命中、灵活走位，并把握相位出现的时机。
整体玩法围绕“选择角色与星体构筑 → 普攻和技能积累星能、触发相位 → 释放相位必杀 → 挑战地牢房间与首领”展开，强调即时操作、角色差异和构筑组合。

# 《星刃：星座觉醒》产品设计文档
> 版本号：V1.0 Final
> 美术风格：2D俯视角平面像素，参考《元气骑士》
> 平台：PC端
> 核心规则要点：
> 1. 每个星座拥有**两个平级主动技能**，技能以功能性为主，不做单纯普攻强化；移除星座被动特质，无常驻被动效果。
> 2. 星体恢复主/辅原有分工：**主星体 → 负责改变星座两个技能的形态与机制质变；辅星体 → 负责相位系统，控制相位触发倾向、阈值、增益效果**。
> 3. PC交互按键适配俯视角WASD+鼠标瞄准模式。

## 一、产品概述
### 1. 基础信息
- **产品名称**：星刃：星座觉醒
- **产品类型**：PC端2D俯视角像素动作地牢闯关游戏
- **美术风格**：对标《元气骑士》16-bit明快像素风，Q版头身角色，干净色块，轻量化像素粒子特效，房间制地牢关卡
- **核心定位**：以「星座双平级技能 + 主星体技能形态质变 + 辅星体相位驱动」为核心的快节奏动作闯关游戏，主打操作手感与构筑搭配，无复杂冗余养成。单局时长3~8分钟。
- **MVP目标**：验证双技能战斗循环流畅度、主星体带来的技能形态差异化、辅星体驱动相位的策略深度。

### 2. 核心机制总纲
**星座定义角色战术定位，主星体改造双技能形态，辅星体驱动相位触发，相位满星能释放星座专属必杀**
完整战斗闭环：
选择本命星座 → 装配1颗主星体 + 1颗辅星体 → 主星体对星座双技能进行形态质变 → 地牢战斗通过普攻与技能命中积攒星能、触发辅星体对应的相位 → 相位激活且星能满时释放星座相位必杀 → 通关解锁新星体，尝试更多构筑组合。

### 2. 星体系统：主星体 / 辅星体分工机制
玩家一局内同时装配**1颗主星体、1颗辅星体**，职责严格分离：
- **主星体**：作用于星座两个平级技能，对两个技能同时做**机制+视觉双重形态质变**，改变技能的攻击逻辑、属性、范围，不影响相位系统；
- **辅星体**：**不改变任何技能形态**，仅控制相位系统：决定相位倾向、触发阈值、相位增益效果。

MVP开放6颗星体：

| 星体 | 主星体效果（同时质变星座双技能） | 辅星体效果（仅驱动相位，不改技能） |

### 3. 相位系统（辅星体驱动）
相位由辅星体主导，触发类型、阈值、增益效果全部由当前装配的辅星体决定。战斗中通过普攻、技能命中自动触发，不打断战斗节奏。

#### 基础4种相位
| 相位类型 | 触发条件 | 基础通用效果 | 适配辅星体 |
| ---- | ---- | ---- | ---- |
| 合相 | 两个技能在1.5秒内同时命中同一敌人 | 双技能伤害+40%，触发技能二次效果（火焰区域扩大、毒伤层数上限提升等） | 太阳、火星 |
| 拱相 | 8秒内累计命中6次（普攻+技能合计） | 星能回复翻倍，全部技能冷却缩减30% | 月亮、木星 |
| 六合 | 连续命中5次，且期间自身未受到伤害 | 全部伤害+20%，技能释放不会被敌人硬直打断 | 水星、土星 |
| 刑克 | 生命值低于30%时释放任意技能 | 本次技能伤害+80%；释放后3秒内自身受到伤害+30% | 火星 |

#### 星座专属相位变体
- 白羊座：合相触发时间阈值缩短至1秒；刑克状态额外获得30%移速加成
- 金牛座：六合状态额外20%减伤；拱相状态护盾耐久+2
- 天秤座：拱相持续时间延长2秒；合相状态技能后摇完全取消
- 天蝎座：刑克状态技能附带10%吸血；合相状态下毒伤叠加层数上限翻倍

### 4. 星座相位必杀系统
触发条件：**相位激活 + 星能槽攒满**，即可释放对应相位的星座必杀。每个星座4种相位对应4套独立必杀，贴合星座形象。

#### 白羊座相位必杀
- 合相·黄道烈焰爆：自身化为火焰流星朝瞄准方向冲撞，终点大范围爆炸，路径敌人持续灼烧
- 拱相·星火连袭：持续5秒，双技能无冷却，每次释放附带火星爆炸，星能回复翻倍
- 六合·锋刃风暴：原地旋转刃风暴，牵引周围敌人造成多段伤害，释放期间霸体
- 刑克·燃命一斩：消耗20%最大生命值，释放巨型火焰斩击，非精英敌人直接斩杀

#### 金牛座相位必杀
- 合相·大地星陨：召唤巨型岩石从天坠落，冲击波大范围伤害，敌人眩晕2秒
- 拱相·岩脉壁垒：全屏岩石屏障，3秒内完全免疫伤害，同时持续回复生命值
- 六合·碎岩连打：连续5次砸地，伤害范围逐次扩大，最后一击全屏破甲
- 刑克·磐石反噬：消耗当前全部护盾，转化一次全屏爆炸；护盾值越高，爆炸伤害越高

#### 天秤座相位必杀
- 合相·星轨审判：展开巨型星盘，向四周发射大量星辉镖，全屏多段伤害
- 拱相·平衡力场：释放时令全体敌人静止2秒，并立即将自身两个技能的当前冷却时间减半；已就绪的技能保持就绪
- 六合·双生星镖：两枚巨型回旋星镖环绕角色持续攻击，角色可自由移动
- 刑克·星轨反转：3秒内，自身受到伤害100%反弹给周围敌人；期间自身无法回血

#### 天蝎座相位必杀
- 合相·深渊毒爆：引爆范围内敌人身上全部毒伤，一次性爆发；毒层越高伤害越高
- 拱相·暗影分身：召唤暗影分身，同步释放角色双技能，持续5秒；分身继承50%伤害
- 六合·毒刃连舞：高速瞬移斩击周围敌人，每次命中叠加毒层，释放期间无敌不可选中
- 刑克·噬魂终结：标记单个敌人，3秒持续掉血；标记结束后，回复等同总伤害的生命值

### 5. 完整战斗循环
1. **普攻攒星能**：使用星座专属普攻攻击敌人，积攒星能；
2. **双技能输出**：消耗星能释放两个经过**主星体形态质变**的星座技能，完成输出、控制、防御；
3. **辅星体驱动相位**：命中满足条件后，辅星体触发对应相位，获得战斗增益；
4. **必杀释放**：相位激活+星能槽满，按下必杀键释放星座相位必杀，清场/斩杀BOSS；
5. **循环重置**：必杀释放后清空相位状态，返还少量星能，进入下一轮战斗循环。

## 三、PC端交互设计（2D俯视角，元气骑士风格）
采用WASD移动+鼠标瞄准分离操作，双技能按键平权，支持按键自定义。

### 默认按键映射
| 操作 | 默认按键 | 说明 |
| ---- | ---- | ---- |
| 八方向移动 | W/A/S/D | 角色移动 |
| 瞄准方向 | 鼠标移动 | 普攻、技能全部朝向鼠标瞄准方向 |
| 普通攻击 | 鼠标左键 | 按住连点触发星座普攻连击 |
| 星座技能一 | 鼠标右键 | 释放主星体质变后的技能一，消耗星能 |
| 星座技能二 | Q | 释放主星体质变后的技能二，消耗星能 |
| 闪避冲刺 | 左Shift | 朝移动方向短距离冲刺，无敌帧，可取消攻击后摇 |
| 相位必杀 | E | 相位激活+星能满时按键高亮，释放必杀 |
| 星体装配界面 | Tab | 战斗外切换主星体、辅星体搭配 |
| 交互 / 开门 | F | 开启宝箱、进入下一房间 |
| 暂停/菜单 | Esc | 打开暂停菜单 |

### UI界面布局
- 左上角：角色血条、星能槽、当前相位状态图标；

### 火焰熔炉：掩体与喷发

加入黑曜石岩堆和损坏的锻造炉。岩堆提供固定掩护，锻造炉前方与地面熔岩裂隙周期性喷火，改变局部安全区域。

机关在造成伤害前至少预告 0.9 秒：炉膛与不规则裂缝逐渐变亮，随后喷发并冷却。熔火领主可以触发场内熔岩裂隙，迫使玩家及时调整站位。

### 深渊秘境：通道与毒沼

加入紫色荧光晶簇、盘结根系和荧光菌囊。晶簇提供固定掩护，根系和菌囊可以破坏；菌囊被击破后立即解除碰撞，并留下持续 4 秒的毒雾。

进入毒沼或菌囊毒雾后，玩家移动速度降至正常速度的 68%；连续停留 1.2 秒后开始受到周期伤害。离开后恢复移动速度，并重置停留时间。根系轻微起伏，菌囊持续鼓胀，荧光粒子从危险区域缓慢升起。

深渊织母可以激活侧翼菌囊，形成短暂的毒雾区域。

### 星核圣殿：动态屏障与星能脉冲

加入破损星仪和周期升降的蓝色晶体屏障。星仪提供固定掩护，晶体屏障在预告后连续升起，阻挡移动与弹道，再逐渐降低并开放通路。

当玩家或敌人仍位于屏障底部时，屏障会等待其离开后再升起，避免角色被卡在障碍物内部。地面星纹机关依次点亮，随后释放星能脉冲；失序星核可以触发屏障和脉冲机关，改变战场路线。

## 5. 主页面音乐播放器

### 5.1 播放与控制规则

主页面右上角新增“音乐”按钮，与“远征”“星体装配”“设置”位于同一排。点击后展开播放控制：

| 操作或场景 | 当前行为 |
| --- | --- |
| 每次打开游戏 | 随机选择目录中的一首音乐，从头播放 |
| 一首正常播放结束 | 按文件名顺序进入下一首 |
| 最后一首结束 | 回到第一首，持续循环 |
| 目录只有一首音乐 | 循环播放该曲 |
| 点击“暂停音乐” | 保留当前播放位置，按钮变为“继续播放” |
| 点击“继续播放” | 从暂停位置继续 |
| 点击“下一首” | 切到下一曲的开头 |
| 暂停时点击“下一首” | 切歌后保持暂停，点击继续才开始播放 |
| 进入关卡、设置或星体装配 | 记住当前曲目和进度，并停止主页音乐 |
| 同一次运行中返回主页 | 继续原曲、原位置；保留手动暂停状态 |
| 关闭后重新打开游戏 | 不恢复此前的音乐位置或手动暂停状态，重新随机选曲 |

随机选择允许连续两次恰好选中同一首，并非强制排除上一首。随机首曲之后仍顺序轮换，不会在每首结束时重新随机。

**最终规则：游戏进度写入本地存档，音乐播放进度只保留在当前运行的内存中。** 旧的 `menu_music.cfg` 不再用于恢复播放进度。

主页音乐使用独立播放器，离开主页时停止，不替代战斗音效；默认音量为 -16 dB，并遵循现有全局静音设置。

### 5.2 音乐目录与 MP3 修复

| 用途 | 目录 |
| --- | --- |
| 项目音乐目录 | `C:\Users\gent7\Desktop\十二星座2d冒险类游戏\music` |
| 桌面发布版音乐目录 | `C:\Users\gent7\Desktop\十二星座2d冒险类游戏\release\Starblade-MVP\music` |
| 将游戏移至其他目录后 | 游戏 EXE 同级的 `music` 文件夹 |

当发布版仍位于当前项目的 `release/Starblade-MVP` 中时，会同时扫描发布目录和项目根目录的音乐。两个目录出现同名曲目时，只加入一次，优先使用 EXE 同级目录中的文件。独立移动出去的游戏使用其 EXE 同级目录。

修复了“项目根目录添加 MP3，但桌面版未扫描该目录”的问题，也支持未经过 Godot 编辑器导入的音频直接加载。

支持的格式为 `.ogg`、`.mp3` 和未压缩 PCM `.wav`。WAV 支持 8／16 位、单声道或立体声；扩展名大小写不影响识别。无法解码的文件会跳过，空目录不会播放声音。

添加音乐的方法：

1. 将完整音频放入上述音乐目录。
2. 建议使用 `01_曲名.mp3`、`02_曲名.ogg` 等前缀控制顺序。
3. 重新进入主页面或重新启动游戏，刷新目录。
4. 用“下一首”检查新增曲目是否可播放。

无需为新增外部曲目重新打包，也不需要复制 Godot 的 `.import` 文件。

## 7. 本地自动存档与继续远征

### 7.1 存档内容

| 分类 | 保存内容 |
| --- | --- |
| 长期进度 | 已解锁章节、主星体、辅星体和称号 |
| 角色与构筑 | 当前星座、主星体、辅星体、选中章节与构筑试炼状态 |
| 设置 | 自定义键位与静音开关 |
| 远征位置 | 当前章节、房间与玩家位置 |
| 玩家状态 | 血量、星能、技能冷却、护盾及相关状态 |
| 战斗进度 | 剩余敌人及血量、Boss 阶段、已破坏或改变的障碍物 |
| 房间交互 | 清房状态、已领取补给和已开启宝箱 |
| 统计与相位 | 远征时间、击杀、伤害统计及相关相位状态 |

已领取奖励不会因重启游戏再次发放，已破坏掩体也不会因重新生成房间而自动恢复。

### 7.2 保存时机与启动流程

游戏会在暂停、房间切换、清房、通关、角色或装配选择、设置变更和正常关闭窗口时保存；运行期间每 5 秒执行一次自动保存。

下次启动时，先读取本地存档，再绘制主页。已解锁内容、构筑与设置直接恢复；存在未完成远征时，主页提供“继续远征”和“重新开始”。

- **继续远征：** 恢复保存的章节、房间、角色构筑与战斗进度。
- **重新开始：** 放弃当前未完成战斗，按当前选择开启新远征，保留已有解锁。
- **结束本次远征：** 主动结束当前战斗，清除其继续入口，保留长期进度。
- **通关或战败：** 不保留已结束战斗的继续入口；正常通关奖励按原规则写入存档。
- **构筑试炼：** 仍不授予正常远征的解锁奖励，沿用原有规则。

加载后重新开始瞬时攻击预警和特效，并给玩家短暂无敌时间。存档用于恢复战斗进展，不重放关闭前的每一帧粒子或飞行弹体。

### 7.3 本地文件、备份与升级

当前桌面版存档目录：

```text
C:\Users\gent7\Desktop\十二星座2d冒险类游戏\release\Starblade-MVP\saves
├── progress.json      主存档
└── progress.json.bak  上一份可读备份
```

开发运行时使用项目根目录的 `saves`。初次启动会自动创建主存档；后续保存保留上一份可读备份。写入先经过临时文件，再替换主文件，降低写到一半留下残缺存档的风险。

主存档无法读取时尝试备份；没有有效存档时使用初始状态。读取过程中会检查版本和基础数据，并拒绝无效房间、未知角色及错误地形计时数据，避免将错误状态带入战斗。

升级 EXE 不会主动覆盖 `saves`。移动游戏时，连同 `saves` 文件夹一起移动即可保留进度；手动备份应同时复制主文件和备份文件。存档不被打进游戏资源包，也不纳入 Git。

本地存档从本版本启用起保存后续进度，无法追溯恢复此前已经退出并被重置的旧进度。异常断电或强制结束进程时，恢复以最近一次成功保存为准。
