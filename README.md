# StarBlade-mvp
《星刃：星座觉醒》是一款 16-bit 像素风格的俯视角动作地牢游戏。玩家选择星座角色，搭配主星体和辅星体，在房间制地牢中与敌人战斗、挑战首领，并通过不断变化的构筑体验不同战斗风格。 每名角色都有专属的普通攻击和两个平级主动技能，没有被动技能。白羊擅长快速近战与突进爆发；金牛挥动重锤、操控碎石，兼具重击与防护；天秤投掷回旋星镖，并用力场控制战场；天蝎则结合毒刃、突刺和持续伤害。移动、攻击、施放技能和闪避需要玩家主动操作，技能选择也会影响走位与输出节奏。 星体搭配是构筑的核心。主星体会同时改变角色两个技能的机制和视觉表现，例如附加火焰、回复、爆炸、聚敌或地形屏障；辅星体则影响相位的触发倾向和增益，不改变技能本身。玩家可以围绕技能强化输出，也可以选择续航、控制或防御路线。
